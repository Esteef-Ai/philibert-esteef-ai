    Install Philibert Code

    Philibert Code is Philibert's coding workshop: a coding agent that writes, tests and fixes programs on this computer, with Philibert's own models and notes. It is an add-on - it goes inside a Philibert install and shares its AI models, so Philibert has to be installed first.

    Needs
    Philibert, set up on this computer. A graphics card with 16 GB and 32 GB of memory make coding jobs fast.
    Takes
    A couple of minutes for the program, then the coding model - about 22 GB to download.
    Adds
    Everything goes into a code folder inside Philibert's folder. Nothing is installed on the computer itself.

    Sign in to GitHub

    Philibert Code is shared privately, like Philibert. Sign in with the GitHub account that was invited - Setup only reads Philibert Code with it, and forgets the sign-in when it closes.
