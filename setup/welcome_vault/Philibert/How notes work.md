# How notes work

Every note is a plain text file (Markdown) in `data\vault` on this drive. The panel
on the right draws them as stars: each folder is a constellation, and a line joins
two notes when one links to the other.

- **Link notes** by putting a note's name in double square brackets, like
  [[Welcome to Philibert]].
- **Open a note:** click its star, or click a link inside a note.
- **Watch Philibert read:** notes light up while Philibert uses them, and the list
  under the vault shows what it read most recently.
- **Drag, zoom, expand:** drag stars around, scroll to zoom, and use the corner
  button for a big view.

Already use Obsidian? The vault is an ordinary Obsidian-compatible folder.
See also [[Keeping things private]].
